# Qol AI — локальный интерактивный макет

Работающий фронтенд-прототип сервиса «текст → видео на языке жестов». Он не требует установки библиотек и запускается обычным Node.js.

## Быстрый запуск в VS Code

1. Откройте эту папку в VS Code.
2. Откройте терминал: **Terminal → New Terminal**.
3. Выполните:

```bash
npm run dev
```

4. Откройте в браузере: <http://127.0.0.1:4173>

Остановка сервера: `Ctrl+C`.

## Проверка production-сборки

```bash
npm run build
npm run preview
```

## Что можно проверить

- переключение русского, казахского и английского интерфейса;
- светлую и тёмную темы;
- адаптивность через DevTools браузера;
- анимации при прокрутке;
- поле ввода, счётчик символов и вставку примера;
- выбор языка жестов, персонажа и формата;
- демонстрационный сценарий генерации и просмотра результата.

## Структура

- `src/index.html` — разметка;
- `src/styles.css` — дизайн, темы и анимации;
- `src/app.js` — локализация и интерактивность;
- `dist/` — готовая production-сборка;
- `scripts/` — сборка и локальный сервер.

> Генерация видео сейчас имитируется в браузере. Для настоящего AI-видео потребуется подключить серверный API модели языка жестов.

## Telegram Mini App

1. Опубликуйте содержимое папки `dist` на публичном HTTPS-адресе.
2. Скопируйте `.env.example` в `.env` и заполните `TELEGRAM_BOT_TOKEN` и `WEB_APP_URL`.
3. Настройте команды и кнопку меню бота:

```bash
npm run setup:bot
```

4. Запустите бота в режиме long polling:

```bash
npm run bot
```

Для постоянной работы держите процесс бота запущенным на сервере. Токен не должен попадать в Git или клиентский JavaScript.
